# Search UI Implementation Plan (UI-only phase)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refero-style search-quality testing UI (search bar, sample grid, ingredient-constellation cards, filtered-out section) styled per DESIGN.md, running fully in the browser on mock data that follows the spec's API contract.

**Architecture:** Static HTML/CSS/vanilla ES modules in `web/`, no build step. `web/mock-api.js` exposes `fetchSearch(q)` / `fetchSamples(n)` returning promises of contract-shaped JSON computed from `web/mock/recipes.json` (hand-authored recipes whose flags come from the real labels CSV). When the backend exists, only `mock-api.js` is swapped for `fetch('/api/...')` calls. The API phase (FastAPI, Python query parser) is deferred.

**Tech Stack:** Vanilla JS ES modules, `node --test` (Node 24), Google Fonts Instrument Serif + Inter. Dev server: `python -m http.server 8000 -d web`.

**Spec:** `docs/superpowers/specs/2026-11-16-search-ui-design.md` (visual tokens: `DESIGN.md`)

## Global Constraints

- Allergen flags (orange dots): `tree_nut, peanut, dairy, gluten, egg, soy, fish, shellfish, sesame`. Other flags: `meat, pork, beef, protein_source`.
- Mock ingredient flags copied from `ingredient_categorization/labeled_manual_combined.csv`: flag set if `<flag>==1` or `maybe_<flag>==1`; `known` false if missing from CSV or `unclear==1`.
- Headline copy exactly: `Describe a dish. We'll find the recipe.`
- Disclaimer copy exactly: `Tags are heuristic, not medical-grade. Always check the original recipe.`
- Placeholder rotation exactly: `spicy ground beef skillet meal`, `dim sum without peanut oil`, `high-protein dinner, no dairy, no nuts`.
- Tokens from DESIGN.md: canvas `#f7f6e3`, ink `#262d29`, orange `#fb5e00`, yellow `#ffff48`, sky `#c1d1df`, footer-muted `#a3a699`, rule `#dadac9`. Grid gap `9.4px`, card radius `18.7px`, action radius `8.4px`, side margin `28.1px`. Fonts: `"Instrument Serif", Georgia, serif` display; `"Inter", Arial, sans-serif` otherwise. No shadows, no white canvas, no pastel panels.
- Recipe text into DOM only via `textContent`/attributes, never `innerHTML`.
- Wordmark placeholder `Recipe Search`. View-only (no judgment saving).
- Modules in `web/*.js` must not touch `document`/`window` at import time, so Node tests can import them.

## Review Focus

1. Exclusion-only query (`no dairy`) → all non-filtered recipes, score 0, sorted by title, not an empty page. Test in Task 1.
2. Exclusion term with no flag (`salsa without cilantro`) → filtered by ingredient-name substring, reason flag `"ingredient"`. Test in Task 1.
3. Blank/whitespace query → UI stays on samples, no search. Test in Task 1 (`fetchSearch` rejects blank) and Task 3 (manual).
4. Link with no scheme or empty → `https://` prefixed, or no link. Test in Task 2.
5. Recipe with 0 or 60 ingredients → 0 / 60 dots, all in bounds. Test in Task 2.

### Task 1: Mock data and mock API

**Files:**
- Create: `web/mock/recipes.json`, `web/mock-api.js`
- Test: `tests/web/mock-api.test.mjs`

**Interfaces:**
- `recipes.json`: list of `{id, title, link, source, ingredients:[{raw, name, flags:string[], known:bool}], flags:{[flag]:1}}`.
- `parseQuery(raw) -> {raw, semantic, exclude:string[], include:[]}`. Clauses `without X`, `no X`, `free of X` (X ends at comma, ` and `, or end) and `X-free`. Term→flags: `nut/nuts → tree_nut, peanut`; `peanut/peanuts/peanut oil → peanut`; `tree nut(s) → tree_nut`; `dairy/milk/cheese → dairy`; `gluten/wheat → gluten`; `egg/eggs → egg`; `soy → soy`; `fish → fish`; `shellfish/shrimp → shellfish`; `sesame → sesame`; `meat → meat`; `pork → pork`; `beef → beef`; otherwise the lowercased term. Exclude deduped, order kept.
- `runSearch(raw, recipes, k = 100) -> {query, results, filtered_out}` (pure). Score = matched/total over semantic tokens (letters only, len ≥ 3, lowercased) found in title or ingredient names, rounded to 2 dp; `why = {matched_terms, passed_filters: exclude}`. Score-0 dropped unless semantic empty (then all kept, sorted by title). Filter reasons, first hit wins, order: flag match `{ingredient, flag}`; non-flag term substring `{ingredient, flag: "ingredient"}`; any exclusion + unknown ingredient `{ingredient, flag: "unknown"}`. Results sorted by score desc.
- `fetchSearch(q) -> Promise<response>` (loads `./mock/recipes.json` via `fetch`, cached; rejects `Error("empty query")` if `q.trim()===""`). `fetchSamples(n = 12) -> Promise<recipe[]>` (first n, result-shaped, score 0).

- [ ] **Step 1:** Author `recipes.json`: 16 recipes, ids 1–16. Must include: spicy ground beef skillet; pork dumplings without peanut oil; dumplings with peanut oil; shrimp har gow; creamy dairy pasta; high-protein lemon chicken quinoa (no dairy/nuts); a za'atar flatbread using `zaatar` (unknown); a salsa with cilantro; one link without scheme (`www.cookbooks.com/Recipe-Details.aspx?id=...`); one empty link. Fill flags from the labels CSV (note: CSV maybe-flags make `oats → soy`, `vegetable broth → fish`; keep them, they're real label behavior worth seeing).
- [ ] **Step 2: Failing tests** (pure functions with inline recipes):

```js
test("without peanut oil", () => assert.deepEqual(parseQuery("dim sum without peanut oil"),
  { raw: "dim sum without peanut oil", semantic: "dim sum", exclude: ["peanut"], include: [] }));
test("multiple no", () => { const q = parseQuery("high-protein dinner, no dairy, no nuts");
  assert.equal(q.semantic, "high-protein dinner"); assert.deepEqual(q.exclude, ["dairy","tree_nut","peanut"]); });
test("free of / -free", () => { assert.deepEqual(parseQuery("cookies free of egg").exclude, ["egg"]);
  assert.deepEqual(parseQuery("gluten-free bread").exclude, ["gluten"]); });
test("peanut recipe filtered with reason", ...)          // reason {ingredient:"peanut oil", flag:"peanut"}
test("unknown only filtered when excluding", ...)        // zaatar recipe kept for "flatbread", flag "unknown" for "flatbread no dairy"
test("exclusion-only returns all passing by title", ...) // "no dairy"
test("unmapped term filters by name", ...)               // "salsa without cilantro" -> flag "ingredient"

```

### Task 2: Constellation and card modules

**Files:**
- Create: `web/constellation.js`, `web/card.js`
- Test: `tests/web/constellation.test.mjs`, `tests/web/card.test.mjs`

**Interfaces:**
- `layoutDots(recipe) -> [{x, y, r, kind: "allergen"|"clean"|"unknown", name, flags}]` in 100×100 space, mulberry32 seeded by `recipe.id`, `r` 2.5–5, `r ≤ x,y ≤ 100−r`. Kind: `unknown` if `!known`, `allergen` if any allergen flag, else `clean`. Export `ALLERGEN_FLAGS`.
- `renderConstellation(recipe, doc = document) -> SVGElement`: `viewBox="0 0 100 100"`, `<circle class="dot dot--<kind>">` each with `<title>` `name — flags` or `name — unknown`.
- `normalizeLink(link) -> string|null`. `renderCard(recipe, {dimmed=false, reason=null} = {}, doc = document) -> HTMLElement`: `<article class="card">` with tile, title, score (2 dp), flag chips (allergens first), why line `matched: a, b · passed: peanut`, reason line `removed: "peanut oil" → peanut`, link `source ↗` (`target="_blank" rel="noopener"`) only if link non-null.

### Task 3: Page shell, styles, wiring

**Files:**
- Create: `web/index.html`, `web/styles.css`, `web/app.js`
- Modify: `README.md` (add "Running the UI": `python -m http.server 8000 -d web`, open `http://localhost:8000`; note data is mock until API phase)

**Interfaces:** consumes `fetchSearch`, `fetchSamples`, `parseQuery` (Task 1), `renderCard` (Task 2).

Layout (spec sketch + DESIGN.md):
- **Masthead:** wordmark left; index nav right (9px hollow-circle markers, 14px; `Search` filled/active, `About` → `#about`).
- **Opening:** sky fade `linear-gradient(#c1d1df, rgba(193,209,223,0))`, 630px, behind masthead. 6–8 inline-SVG orange near-circle blobs (20–90px) around, never over, headline/field; hidden ≤ 767px except two small ones. Headline display serif `clamp(30px, 2.925vw, 42.1px)/1.15`, centered, max 1014px.
- **Search form:** `<form role="search">`, input with 0.5px ink border, 8.4px radius, ~20px text, max 760px; submit = outline button, yellow hover. Placeholder rotates every 4s (off under `prefers-reduced-motion`). `?q=` read on load, written on submit (`history.replaceState`).
- **Chips:** `semantic: "…"`, `exclude: peanut` per item; hidden before search. **Disclaimer** always visible below.
- **Results:** ruled intro (1px ink rule, heading `24 results` or `Sample recipes`). Grid 4 cols, gap 9.4px, row gap 46.8px; 2 cols ≤ 991px; 1 col ≤ 479px. Tile: square, 18.7px radius, paper fill, 0.5px ink border; `.dot--allergen` fill orange, `.dot--clean` ink, `.dot--unknown` no fill + 1px ink stroke.
- **Filtered out:** `<details>` summary `Filtered out (N)` as ruled row; dimmed cards (opacity .55) with reason; hidden when N = 0.
- **States:** blank submit → samples; error → `Search failed. Try again.`; zero results → `No recipes matched. Check the filtered-out list below.`
- **Footer** `id="about"`: charcoal band, cream text, About copy (purpose, disclaimer, RecipeNLG credit), wordmark in display serif scaled to container width (`clamp` + `vw`).
