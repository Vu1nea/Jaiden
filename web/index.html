    About

    A testing bench for semantic recipe search. Describe a dish in plain words, add exclusions like “no dairy”, and see what ranks, what gets filtered, and why.

    How filtering works

    Ranking is fuzzy; exclusions are exact. Every ingredient is labeled once, and a recipe is removed if any ingredient carries an excluded flag, or if an ingredient is unlabeled while you're excluding something.
